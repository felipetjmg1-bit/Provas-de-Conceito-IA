# PROVAS DE CONCEITO IA · fluxo passo a passo

Repositório documental para organizar hipóteses e validações.

## 1. FORMULAR HIPÓTESE

Descrever problema, usuário e hipótese tecnológica.

## 2. DEFINIR ESCOPO

Listar entradas, saídas, dependências e limites da PoC.

## 3. CONSTRUIR DEMONSTRAÇÃO

Implementar o menor fluxo que permita testar a hipótese.

## 4. MEDIR E REGISTRAR

Definir critérios, dados de teste e evidências reproduzíveis.

## 5. DECIDIR EVOLUÇÃO

Documentar riscos e próximos passos com base nos resultados.

## Resultado e limites

Estrutura de documentação. Cada PoC precisa de código e evidência próprios para ser considerada executável.
